# TVSOS 前端指标展示形式报告

> 生成时间：2026-09-14（沙箱系统落地后）。范围：当前前端所有指标的展示位置、形式与数据流。
> 涉及文件：`components/statistics2.vue`（实时大屏）、`views/experimentResult.vue`（终态结果）、`views/experimentCompare.vue`（跨实验对比）、`views/header.vue`（实验状态条）、`components/mapContainer.vue / infoPanel.vue / taskManage.vue / vehicleList.vue`（地图屏）。

---

## 0. 展示体系总览

沙箱化后，指标展示分三个层级：

| 层级 | 页面 | 时机 | 数据源 |
|---|---|---|---|
| 运行期实时监控 | 实验视图第二屏「统计分析」（statistics2.vue） | 实验 running 时 | WS `/ws/stats` 每 3s 推送 snapshot，断线 15s 轮询 `/report/realtime` 兜底 |
| 终态结果集 | 实验结果页（experimentResult.vue） | 实验 finished 后 | `GET /experiments/:id/result`（experiment_result + metric_snapshot 时序） |
| 跨实验对比 | 对比页（experimentCompare.vue） | 任意时刻 | `GET /compare?exp_ids=...`（各实验 primary_metrics） |

## 1. 运行期实时大屏（statistics2.vue，实验视图第二屏）

### 1.1 顶部 KPI 卡片区（4 张，可点击）

| 卡片 | 指标 | 展示形式 |
|---|---|---|
| 总吞吐量 (吨) | T0 总吞吐 | 大数字 + 趋势文案（↑/↓ x% 较上一轮，绿/红色）；点击弹「深度分析」overlay：面积折线趋势图 |
| 货物待处理量 | 待处理吨数 | 大数字 + 阈值告警文案（>2000 吨"高压区间，需立即分流"红色 / 上升"建议增派" / "压力可控"）；点击弹波动柱状图 |
| 调度总成本 | 综合成本 F | ¥ 大数字（橙色）+ "预算上行/回落 x%"；点击弹青色面积趋势图 |
| 运输效率 (综合) | 载重利用率×3 折算 | 百分比大数字 + 进度条 + "效率提升/回落"；点击弹即时诊断仪表盘 |

趋势数据来源：进程内 trendStore（最近 24 个采样点，实验启动时清零）。

### 1.2 主图区（3 栏）

| 位置 | 图表 | 指标内容 |
|---|---|---|
| 左 | 环形饼图「车辆分布」 | 六类车型数量占比（vehicle.tybe） |
| 中 | 柱状图「货物需求构成 (吨)」 | 各货类待处理需求吨数 |
| 右 | 仪表盘「利用率监控」+ 迷你统计 | 载重利用率指针仪表；上方两行小字：总等待时间(h)、总空驶里程(km) |

### 1.3 底部行（3 栏）

| 位置 | 内容 | 形式 |
|---|---|---|
| 左 | 空驶/满载比 + 等待/运输比 | 双柱对比图 |
| 中 | 轮播卡 ×2 | 「个体货车运能 (T·km)」「工厂装卸耗时 (min)」各展示 最大/最小/平均/中位 四宫格 |
| 右 | 损耗盒 | 三行带色点数据：总损耗(吨·h)、总运能(吨·km)、装卸总耗时(min) |

### 1.4 分视角章节面板（8 章 tab + 指标卡网格）

顶部 tab 切换章节，每章若干指标卡：卡片含 **指标编号徽标 + 名称 + 大数值带单位 + 口径注释 + "实时"状态徽标**。连接状态行显示「实时推送 (WebSocket 已连接) / 轮询兜底中 (15s)」。

| 章 | 编号 | 指标 | 卡片数值形式 | 注释文案 |

### 1.5 随机事件流（面板底部）

列表逐条展示最近 10 条随机事件：**类型徽标**（refuse/rest/weather/accident 四色）+ 描述 + 车牌号 + 虚拟时刻 + 影响时长(min) + 状态(active/resolved)。头部汇总行：事故 x · 拒单 x · 维修 x 辆 · 休息 x 人。

## 2. 实验视图辅助展示

| 位置 | 内容 | 形式 |
|---|---|---|
| header 实验状态条 | 虚拟时钟时刻 + 实验进度 | 时钟图标 + 等宽字体时刻文本 + el-progress 进度条（每 5s 轮询 /experiments/:id/status） |

## 3. 终态结果页（experimentResult.vue）

实验 finished 后自动跳转，或从实验记录「查看结果」进入：

| 区块 | 指标 | 形式 |
|---|---|---|
| 主目标卡（12 张） | C2 单位成本 / U2 装载率 / U4 空驶率 / T2 响应P95 / F1 基尼 / G2 吨公里碳排 / 总成本 / 总吞吐 / 车祸数 / 拒单数 / 虚拟tick数 / SA均耗时 | 蓝色大数字卡片网格 |
| 指标时间序列 | 总成本 / 总吞吐 / 空驶率 | 三系列平滑折线图，x 轴为虚拟时钟时刻（metric_snapshot 每 6 tick 一点） |
| SA 收敛曲线 | 每温度层最优 cost | 对数轴折线图（算法性能，对齐 PDF 结果层） |
| 终态指标全量 | summary 全部字段 | el-descriptions 三列边框表（嵌套对象 JSON 拍平） |
| 参数快照 | 实验参数 TOML 全文 | 等宽字体 pre 块（复现依据） |

## 4. 跨实验对比页（experimentCompare.vue）

| 区块 | 内容 | 形式 |
|---|---|---|
| 实验选择器 | 本沙箱已完成实验多选 + 跨沙箱 ID 追加 | el-select multiple + 输入框 |

| 关键指标柱状 | 总成本 / 总吞吐 | 分组柱状图，每实验一系列 |
| 结果明细表 | 8 项主指标 × N 实验 | 表格：行=指标，列=实验（#id+名称） |
| 参数差异 | 各实验 TOML 相对首个实验的逐行 diff | 等宽文本行（"本实验: x | 基准: y"），完全一致时绿色提示 |

## 5. 数据流与口径备注

1. 实时大屏所有数值来自后端 `RealtimeSummary`（约 50 字段），WS 推送优先、轮询兜底；新增 summary 字段需同步 statistics2.vue 四处（dynamicData 声明 / initDynamicStats / mapSnapshotToDynamicData / applySnapshot）。
2. 沙箱化后所有时长/时刻均为**虚拟时钟**口径；R1-R3/T1 观测窗口为实验生命周期；M/A2/C1 累计器实验启动清零。
3. 事件流与车辆展示一律用车牌号（License），不用内部 ID。
4. 已移除指标（S1-S3/C3/A1/F3）不在任何页面出现，勿加回。
